# Plan 06-03: Google Gemini AI HR Assistant & Frontend Billing / AI Chat UI

**Phase:** 06 — Subscriptions, Gemini AI Assistant & Security Hardening  
**Status:** In Progress  

## Objective
Implement the Google Gemini AI HR Policy Assistant backend module with context injection, role-aware guardrails, and frontend UI for Subscriptions (`/dashboard/billing`) and AI Chat (`/dashboard/ai-assistant`).

## Tasks
1. **Google Gemini AI Assistant Backend (`AiAssistantService`)**:
   - `AiAssistantModule`, `AiAssistantController`, `AiAssistantService`.
   - Injects system prompt with ZenHR policies (3-month probation, reporting line workflows, attendance rules).
   - Enforces data isolation and privacy guardrails (refuses to leak cross-employee salaries or confidential executive data).
   - Role-scoped context: includes requester's own profile and leave balance in prompt.
2. **Frontend UI Experience**:
   - `/dashboard/billing`: Plan Comparison (Basic vs Premium feature matrix), Current Status badge (Active/Trialing/Past Due), "Upgrade to Premium" Stripe Checkout trigger, Customer Portal button.
   - `/dashboard/ai-assistant`: Conversational chat widget with preset quick prompts (e.g., "What is the probation leave policy?", "How do I request equipment?"), message history, and typing indicators.
3. **Unit Tests & Typechecks**:
   - `ai-assistant.service.spec.ts` passes.
   - Full frontend and backend typechecks pass.
