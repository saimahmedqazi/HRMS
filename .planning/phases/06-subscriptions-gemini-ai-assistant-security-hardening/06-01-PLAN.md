# Plan 06-01: Subscription Tiers, Feature Gating Guard & Stripe Webhook Engine

**Phase:** 06 — Subscriptions, Gemini AI Assistant & Security Hardening  
**Status:** In Progress  

## Objective
Implement multi-tenant subscription tiers (Basic vs Premium), feature gating decorator and guard, Stripe prebuilt checkout session creation, customer portal link generation, and resilient Stripe webhook processing.

## Tasks
1. **Subscription Gating**:
   - `@RequireSubscriptionTier(SubscriptionTier.PREMIUM)` decorator.
   - `SubscriptionTierGuard`: Checks tenant's active tier; throws `ForbiddenException('This feature requires a ZenHR Premium tier subscription.')` if on Basic.
2. **Subscriptions Service & Stripe Engine**:
   - `ensureSubscription(companyId)`: Auto-creates default Basic subscription with 14-day trial.
   - `createCheckoutSession(companyId, returnUrl)`: Generates Stripe Checkout widget redirect URL.
   - `createCustomerPortalSession(companyId, returnUrl)`: Generates Stripe billing management link.
   - `handleStripeWebhook(payload, signature)`:
     - Handles `checkout.session.completed`, `customer.subscription.updated`, `invoice.payment_succeeded`, `invoice.payment_failed`.
3. **Unit Tests**:
   - `subscription-tier.guard.spec.ts`: Tests blocking Basic tenants on Premium routes, allowing Premium tenants.
   - `subscriptions.service.spec.ts`: Tests checkout session creation and webhook handling.
