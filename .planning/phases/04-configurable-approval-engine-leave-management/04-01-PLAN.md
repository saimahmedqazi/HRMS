# Plan 04-01: Generic Reporting-Line Approval Engine & Probation Gating

**Phase:** 04 — Configurable Approval Engine & Leave Management  
**Status:** In Progress  

## Objective
Implement the generic approval engine that resolves approver chains dynamically from the employee's reporting hierarchy, step audit logging, auto-skipping, and strict 3-month probation gating exclusively for `EMPLOYEE` role.

## Tasks
1. **Approval Engine Core**:
   - `ApprovalEngineService`:
     - `resolveApprovers(requesterEmployee)`: Computes step 1 approver and step 2 approver.
     - `canApproveStep(request, step, user)`: Validates calling user is authorized approver for this step.
     - `recordStepDecision(request, step, decision, notes, user)`.
2. **Probation Gating Service**:
   - `assertCanRequestLeave(employee)`:
     - If `user.role === 'EMPLOYEE'` and `employee.hireDate + 90 days > now`:
       throws `ForbiddenException`.
3. **Leave Type Settings**:
   - `GET /api/v1/leave/types`: List active leave types in company.
   - `PATCH /api/v1/leave/types/:id`: Update annual quota, mandatory reason toggle, mandatory document toggle.
4. **Unit & Integration Tests**:
   - Probation gating test (blocks probationary employee, allows regular employee, allows manager).
   - Approval chain dynamic resolution tests for Employee, Team Lead, and Dept Manager.
