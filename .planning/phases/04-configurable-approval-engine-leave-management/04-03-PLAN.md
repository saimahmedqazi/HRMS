# Plan 04-03: Resource Request Workflow & Frontend Leave/Approval UI

**Phase:** 04 — Configurable Approval Engine & Leave Management  
**Status:** In Progress  

## Objective
Implement Resource Requests (equipment / software) and the frontend UI for Leave Requests, Probation Gating Banner, Leave Approvals, and HR Leave List Modal with prescription download.

## Tasks
1. **Resource Requests Backend**:
   - `POST /api/v1/resources/requests`: Team Lead requests equipment/software.
   - `GET /api/v1/resources/requests`: Scoped list.
   - `PATCH /api/v1/resources/requests/:id/approve`: Dept Manager approval.
   - `PATCH /api/v1/resources/requests/:id/fulfill`: Fulfilling department marks fulfilled.
2. **Frontend UI Experience**:
   - Leave Dashboard (`/dashboard/leave`):
     - Probation Banner: Displays warning and disables submission if on 3-month probation.
     - Leave Balances Cards: Allocated, Used, Pending breakdown for Casual, Sick, Annual.
     - "Request Leave" Modal: Leave type selector, start/end date, reason, prescription file uploader.
     - My Leave Requests list with status badges (`Pending`, `Approved`, `Rejected`, `Cancelled`).
   - Leave Approvals Queue (`/dashboard/leave-approvals`):
     - Approval queue for Team Leads and Dept Managers.
     - One-click "Approve" or "Reject with notes".
     - HR modal with direct prescription download button.
3. **Unit & Integration Tests**:
   - Resource request workflow test.
   - Frontend and backend typechecks.
