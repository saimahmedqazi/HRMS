# Plan 02-03: Cloud Storage Pipeline & Frontend Organization/Employee UI

**Phase:** 02 — Organization Hierarchy, Employee Management & Cloud Storage  
**Status:** Completed  

## Objective
Implement Cloudinary/S3 file storage service with Multer upload endpoints, storing exclusively secure HTTPS URLs in PostgreSQL, and build frontend pages for Department/Team management, Employee Directory, and Employee Profile with status badges and photo uploads.

## Tasks
1. **Cloud Storage Backend Service**:
   - `StorageService` in `src/common/storage/storage.service.ts`:
     - Cloudinary SDK integration for image/document uploads.
     - Mock upload provider fallback when API keys are absent.
     - Enforce file type whitelist (`image/jpeg`, `image/png`, `image/webp`, `application/pdf`).
     - Enforce file size limit (5MB image, 10MB document).
   - `POST /api/v1/employees/:id/avatar` — Upload and update employee profile picture.
   - `POST /api/v1/employees/:id/documents` — Upload employee document (contract, ID proof, certification).
   - `GET /api/v1/employees/:id/documents` — List uploaded employee documents.
2. **Frontend UI Components**:
   - Status Badge Component: Colors and styling for all 6 employee statuses (`Active` emerald, `On probation` amber, `Suspended` red, `On leave` blue, `Resigned` zinc, `Terminated` destructive).
   - Organization Structure Page (`/dashboard/departments`): Tree/grid view of departments, designations, and teams with manager assignment modals.
   - Employee Directory Page (`/dashboard/employees`): Searchable, filterable list with pagination, status badges, and quick actions.
   - Employee Detail Page (`/dashboard/employees/[id]`): Tabbed interface (Overview, Personal, Job & Hierarchy, Emergency Contacts, Documents) with avatar uploader.
3. **Unit & Integration Tests**:
   - Storage service mock and MIME type validation test.
   - File upload controller test.
