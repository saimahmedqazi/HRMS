# Plan 03-02: Work Timer, Break Overstay Tracking & Overtime Engine

**Phase:** 03 — Attendance, Work Timer & Real-Time Alert Engine  
**Status:** Completed  

## Objective
Implement the Work Timer module (gated by subscription tier check for Premium), break tracking with pause/resume intervals, break overstay detection, and overtime calculation on session completion.

## Tasks
1. **Work Timer Service**:
   - `POST /api/v1/timer/start`:
     - Checks company subscription tier (must be `PREMIUM` or active).
     - Initializes or resumes `WorkTimerEntry` for today.
   - `POST /api/v1/timer/pause`:
     - Records break start time (`breakStartTime`).
     - Updates status to `PAUSED`.
   - `POST /api/v1/timer/resume`:
     - Calculates duration of current break.
     - Increments accumulated `breakMinutes`.
     - Checks if total break duration exceeds shift threshold (e.g. 60m).
     - If exceeded, triggers break alert event.
   - `POST /api/v1/timer/stop`:
     - Calculates total active work duration.
     - Computes `overtimeMinutes = Math.max(0, workMinutes - shiftStandardMinutes)`.
     - Synchronizes minutes with today's `AttendanceRecord`.
   - `GET /api/v1/timer/today`:
     - Returns live timer entry with current status, elapsed work seconds, and break seconds.
2. **Unit & Integration Tests**:
   - Timer start/pause/resume/stop lifecycle tests.
   - Break calculation and overstay threshold trigger test.
   - Overtime synchronization with AttendanceRecord test.
