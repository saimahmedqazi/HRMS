# Plan 03-04: Nightly Absence Marking Cron & Attendance/Work Timer Frontend UI

**Phase:** 03 — Attendance, Work Timer & Real-Time Alert Engine  
**Status:** Completed  

## Objective
Implement scheduled nightly absence marking cron job (running at 23:59 daily) and frontend UI for Employee Check-in/out, Live Work Timer widget, HR Exceptions Queue, and Attendance Logs.

## Tasks
1. **Nightly Absence Marking Job**:
   - NestJS `@Cron('59 23 * * *')` (with BullMQ job backing).
   - Finds all active employees scheduled for work today who have no attendance record.
   - Checks if employee is on approved leave (`LeaveRequest.status === APPROVED`). If on leave -> marks `ON_LEAVE`.
   - Checks if today is holiday or weekend -> skips or marks `HOLIDAY`/`WEEKEND`.
   - Otherwise -> creates `AttendanceRecord` with `status: ABSENT`, `markedBySystem: true`.
2. **IP Whitelist Module**:
   - `GET /api/v1/attendance/ip-whitelist`
   - `POST /api/v1/attendance/ip-whitelist`
   - `DELETE /api/v1/attendance/ip-whitelist/:id`
3. **Frontend UI**:
   - Attendance Dashboard (`/dashboard/attendance`):
     - Daily punch widget (Onsite / Remote toggle, punch in / punch out button, live work duration counter).
     - Live Work Timer widget (Start, Pause, Resume, Stop buttons with live digital timer display).
   - HR Exceptions Queue (`/dashboard/attendance/exceptions`):
     - Table of pending unauthorized remote check-ins.
     - One-click "Approve" (converts to `Present (Remote)`) or "Reject" (marks `Absent`).
   - Attendance History Log (`/dashboard/attendance/history`):
     - Scoped attendance table with date filter, export buttons, and status badges.
4. **Unit & Integration Tests**:
   - Absence cron logic test.
   - IP whitelist validation test.
