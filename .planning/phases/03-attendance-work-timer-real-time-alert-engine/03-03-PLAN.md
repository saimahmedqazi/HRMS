# Plan 03-03: Real-Time WebSocket Alerts & Stakeholder Email Notification Engine

**Phase:** 03 — Attendance, Work Timer & Real-Time Alert Engine  
**Status:** Completed  

## Objective
Implement real-time WebSocket communication via Socket.IO gateway for instant break alerts and attendance exception notifications, broadcasting to Team Lead, Department Manager, and CEO, backed by concurrent Nodemailer email dispatch.

## Tasks
1. **Socket.IO Gateway Setup**:
   - `AttendanceGateway` with namespace `/ws/attendance`.
   - JWT authentication on connection: extracts token from cookie/handshake, joins role and company rooms (`company_{companyId}`, `user_{userId}`, `lead_{teamId}`, `dept_{departmentId}`, `ceo_{companyId}`).
2. **Break Overstay Alert Engine**:
   - When employee break exceeds threshold:
     - Emits `break_alert` WebSocket event payload:
       `{ employeeId, employeeName, departmentName, shiftLimitMinutes, actualBreakMinutes, timestamp }`
     - Targeted rooms:
       - Team Lead of employee
       - Department Manager of employee
       - Company Admin (CEO)
     - Concurrently triggers `MailService.sendBreakAlertEmail` to all three stakeholders.
     - Creates in-app `Notification` records.
3. **Unit & Integration Tests**:
   - WebSocket connection authentication test.
   - Break alert emission to stakeholder rooms test.
   - Concurrent email dispatch test.
