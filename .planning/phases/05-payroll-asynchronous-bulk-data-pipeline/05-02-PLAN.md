# Plan 05-02: PDF Payslip Generation (Single & Bulk) & Employee Payslip Access

**Phase:** 05 — Payroll & Asynchronous Bulk Data Pipeline  
**Status:** In Progress  

## Objective
Implement PDF payslip generation using `pdfkit`, single and bulk payslip downloads, and secure employee payslip access.

## Tasks
1. **PDF Generator Service (`PdfService`)**:
   - Streams formatted professional payslip PDF:
     - Company header & logo, Employee ID, designation, department.
     - Pay period (Month, Year).
     - Earnings column (Base salary, allowances, bonuses).
     - Deductions column (Taxes, standard deductions).
     - Net pay highlight.
2. **Payslip Controller & Endpoints**:
   - `GET /api/v1/payroll/payslips`: Scoped list of payslips (`EMPLOYEE` sees only own; `HR`/`ADMIN` sees company).
   - `GET /api/v1/payroll/payslips/:id`: Details of a payslip.
   - `GET /api/v1/payroll/payslips/:id/pdf`: Downloads PDF payslip.
   - `GET /api/v1/payroll/runs/:runId/pdf-bulk`: Downloads consolidated PDF of all payslips for that run.
3. **Unit Tests**:
   - `pdf.service.spec.ts`: Tests payslip PDF stream generation and buffer size validity.
   - Data scope checks on payslip retrieval.

## Verification
