# Plan 05-03: Asynchronous Bulk Employee Import Pipeline & Frontend Payroll UI

**Phase:** 05 — Payroll & Asynchronous Bulk Data Pipeline  
**Status:** In Progress  

## Objective
Implement asynchronous bulk employee import with validation preview, error reporting, and the frontend interfaces for Payroll Runs, Department Summary, Payslip Downloads, and Bulk Import.

## Tasks
1. **Bulk Employee Import Pipeline (`BulkImportService`)**:
   - `POST /api/v1/employees/bulk/preview`:
     - Parses uploaded Excel sheet (.xlsx, .csv).
     - Validates mandatory fields and email uniqueness.
     - Returns preview metrics: valid count, invalid count, line-item errors.
   - `POST /api/v1/employees/bulk/execute`:
     - Imports valid rows into DB transactionally.
     - Generates default credentials, initial leave balances, and shifts.
     - Produces completed import report.
2. **Frontend UI Experience**:
   - `/dashboard/payroll`: HR Manager payroll runs execution widget, salary structure manager, and payslip list.
   - `/dashboard/payroll-view`: Department Manager aggregate read-only summary (headcount, gross, net; individual salaries hidden).
   - `/dashboard/my-payslips`: Employee personal payslip download history with one-click PDF download.
   - `/dashboard/bulk-import`: Excel upload widget, interactive table preview of valid/invalid rows, error report, and one-click execution.
3. **Unit Tests & Typechecks**:
   - `bulk-import.service.spec.ts` passes.
   - Frontend and backend typechecks pass.
