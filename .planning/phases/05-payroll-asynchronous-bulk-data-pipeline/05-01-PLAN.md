# Plan 05-01: Salary Structures, Monthly Payroll Execution & Dept Summary Security

**Phase:** 05 — Payroll & Asynchronous Bulk Data Pipeline  
**Status:** In Progress  

## Objective
Implement salary structures with allowances and progressive tax calculations, monthly payroll run batch execution, and the Department Manager summary with strict role gating (forbidden for Team Leads).

## Tasks
1. **Salary Structure & Calculations**:
   - `PayrollService.createStructure`: Default or custom structures with base salary, allowances, deductions, and tax brackets.
   - `PayrollService.calculatePayslip`: Computes gross, allowances, deductions, taxes, and net salary.
2. **Monthly Payroll Execution**:
   - `POST /api/v1/payroll/runs`: Executes payroll for all active employees for given month and year.
   - Emits in-app `PAYSLIP_GENERATED` notifications.
3. **Department Payroll Summary with Role Gating**:
   - `GET /api/v1/payroll/department-summary`:
     - Allowed for `DEPARTMENT_MANAGER` (scoped to their department), `HR_MANAGER`, and `COMPANY_ADMIN`.
     - Explicitly throws `ForbiddenException` for `TEAM_LEAD` and `EMPLOYEE`.
     - Returns aggregate statistics (`headcount`, `totalGross`, `totalNet`, `totalDeductions`).
4. **Unit & Integration Tests**:
   - `payroll.service.spec.ts`:
     - Tax and net salary calculation tests.
     - Payroll run batch generation test.
     - Department summary access control test (allows Dept Manager, forbids Team Lead).
