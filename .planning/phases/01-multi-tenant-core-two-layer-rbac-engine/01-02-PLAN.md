# Plan 01-02: Authentication System

**Phase:** 01 — Multi-Tenant Core & Two-Layer RBAC Engine
**Status:** Completed

## Objective
Build production-quality authentication: JWT access/refresh tokens in httpOnly cookies, rotating refresh tokens, bcrypt password hashing, email verification, forgot/reset password, rate limiting, account lockout, and optional TOTP 2FA.

## Tasks

### 1. AuthModule Core
- [x] `AuthModule`, `AuthController`, `AuthService`
- [x] Register company + admin user endpoint
- [x] Login endpoint with JWT issuance
- [x] Logout (clear cookies)
- [x] Refresh token rotation

### 2. JWT Strategy
- [x] `@nestjs/passport` + `passport-jwt`
- [x] Access token (15-min) + refresh token (7-day)
- [x] Both stored in httpOnly, sameSite=lax, secure cookies
- [x] Rotating refresh tokens: hash stored in DB, invalidate on use

### 3. Security Features
- [x] `bcrypt` password hashing (rounds: 12)
- [x] Email verification flow (token → email → verify endpoint)
- [x] Forgot password / reset password flow
- [x] `@nestjs/throttler` rate limiting (auth endpoints: 5 req/min)
- [x] Account lockout after 5 failed attempts (15-min lockout)
- [x] Login captures IP + user-agent + coarse geolocation

### 4. TOTP 2FA Module
- [x] Generate TOTP secret + QR code URI
- [x] Verify TOTP token
- [x] Backup codes (8 codes, bcrypt hashed)
- [x] Enable/disable 2FA

### 5. AsyncLocalStorage Context
- [x] `RequestContext` service with `companyId`, `userId`, `role`
- [x] Middleware populating context from JWT on every request

## Verification
- [x] POST /api/v1/auth/register creates company and admin user
- [x] POST /api/v1/auth/login sets httpOnly cookies
- [x] POST /api/v1/auth/refresh rotates refresh token
- [x] POST /api/v1/auth/logout clears cookies
- [x] 6th failed login triggers 15-min lockout
- [x] Rate limiter blocks >5 req/min to auth endpoints
