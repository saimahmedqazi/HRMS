# Plan 01-03: Two-Layer RBAC, Data Scope & Frontend Shell

**Phase:** 01 — Multi-Tenant Core & Two-Layer RBAC Engine
**Status:** Completed

## Objective
Implement Prisma tenant extension, RolesGuard, DataScopeService, Super Admin Support Mode, and the Next.js frontend shell with login, protected routes, and role-adaptive sidebar.

## Tasks

### 1. Prisma Tenant Extension
- [x] `TENANT_MODELS` set (opt-in tenancy)
- [x] Prisma Client extension auto-injecting `companyId` from AsyncLocalStorage
- [x] Platform models (Company, User with SUPER_ADMIN) bypass extension

### 2. RBAC Guard & Data Scope

### 3. Super Admin Support Mode

- [x] Every action in Support Mode writes to AuditLog
